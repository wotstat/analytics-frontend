# ZoomChartComponent

Компонент `InteractionController` для управления окном графика: пан, зум, инерция,
жёсткие или эластичные лимиты и синхронизация между графиками.

```ts
new ZoomChartComponent({
  chart,
  zoom: true,
  panDirection: 'horizontal',
  wheelInput: 'auto',
})
```

`panDirection` задаёт активные оси: `horizontal`, `vertical`, `all` или `false`.
Остальные опции — в [ZoomChartComponent.ts](ZoomChartComponent.ts).

Колесо по вертикали масштабирует, по горизонтали панорамирует X. Тачпад панорамирует
по активным осям и масштабирует через pinch; hover сохраняется. Начальное направление
одноосевого жеста определяет, обрабатывает его график или страница.
Определение устройства — в [wheelInput](../../../wheelInput/readme.md).

Жесты и анимации меняют внутренние границы `raw`, из которых получаются отображаемые
границы с учётом лимитов. Синхронизация через `boundsSync` проходит через компонент,
чтобы каждый график сохранял собственную авто-подгонку второй оси.

Примеры и ручная проверка: `/debug/chart/interaction#zoom-pan`.
