# Wheel-ввод

[wheelInput.ts](wheelInput.ts) — синглтон, который наблюдает ввод на всей странице
и хранит общий для графиков профиль устройства. Подключается через `BaseInteractionController`.

Опция `ZoomChartComponent.wheelInput` выбирает схему управления:

- `auto` — автоматический профиль, изначально колесо;
- `wheel` — вертикальная прокрутка масштабирует, горизонтальная панорамирует X;
- `trackpad` — прокрутка панорамирует, pinch масштабирует.

Автодетект включает тачпад по диагональному wheel или нативному pinch на macOS,
возвращает колесо после нескольких завершённых одноосевых жестов. Это эвристика;
явная настройка действует только на выбранный график и имеет приоритет.

[WheelSmoothing.ts](WheelSmoothing.ts) отдельно определяет плавность колеса для анимации зума.
Проверка профиля и ввода: `/debug/chart/interaction#zoom-pan`.
