# Игровая доменная модель (`src/shared/game/`)

## Две игры: Lesta («Мир танков», RU) и Wargaming (World of Tanks, EU/NA/ASIA)

- `wot.ts`: тип `GameVendor = 'wot' | 'mt'` (`mt` = Мир танков/Lesta), `GameRegion = 'RU' | 'EU' | 'NA' | 'ASIA' | 'CT' | ...`. Конвертации `gameToRegion` / `regionToGame` (RU/RPT/CT → `mt`). `accountLink(bdid, name, region)` — ссылка на профиль игрока на портале.
- Предпочтение игры пользователем — `src/shared/global/globalPreferred.ts`: `preferredGame` в localStorage (`'mt' | 'wot' | 'any' | 'unknown'`), `preferredGameOrDefault` (дефолт `mt`).
- Версии игры: `gameVersion.ts`; выбор версии в фильтрах — `selectors/gameVersionSelector/`.

## Режимы боёв (`battleModes.ts`)

- `BattleMode` и `BattleGameplay` допускают неизвестные строковые коды. Списки `battleModes` и `battleGameplays` перечисляют известные технические коды без привязки к доступности в конкретной игре. Сочетания режимов и геймплеев и правила архивности находятся рядом с селектором в `selectors/battleMode/catalog.ts`.
- `battleModeNames`, `battleGameplaysNames`, `battleGameplaysOverrides` — локализация и переопределения геймплея внутри режима. `battleGameplayName(gameplay, mode?)` и `battleModeName(mode, gameplay?)` возвращают технический код при отсутствии перевода. Категорий и составных групп селектора здесь нет.
- `wot.ts` сохраняет прежние `customBattleModes` / `CustomBattleModeKey` для URL-параметра `?mode=` других страниц, `gameplayTypes`, `modeCount` и `shellNames`. Новый селектор не строится на этих устаревших словарях.
- Comp7/Натиск-специфика: `comp7/utils.ts` + `comp7/i18n.json`, иконки рангов `comp7/rank/RankIcon.vue`.

### Сезонные правила рангов Натиска

Хелперы в `comp7/utils.ts` принимают игру и сезон (по умолчанию `mt` / `latest`).
`hasEliteDivisions(game, season)` включает дивизионы C/B/A у `fifth` и `sixth` для МТ начиная с
`comp7_6_1`; старые сезоны МТ и все сезоны WoT используют бездивизионные `fifth` / `sixth`.
Неизвестные форматы id сезона сохраняют старую систему. Явный `Rank` без буквы означает ранг целиком
даже в новом сезоне. Тип `Division` включает обе системы.

- `getDivisionByRating(rating, game, eliteRating, season)` и `getRankByRating(...)` сохраняют прежние
  первые три аргумента. У Чемпиона в новой системе пороги C/B/A — 2650/3050/3450.
- `EliteRating` — либо один числовой порог Легенды, либо `{ C, B, A }` с порогами рейтинга для
  топ-5%/3%/1%. Только полный набор позволяет определить `sixth_C` / `sixth_B` / `sixth_A`.
  С одним числом возвращается общий `sixth`, без выдуманной буквы. Неположительный порог считается неизвестным.
- `getDivisionsByRank`, `getNextDivision`, `getPrevDivision` принимают `(rankOrDivision, game, season)`.
  `getRatingForDivision` / `getRatingIntervalForDivision` дополнительно принимают `eliteRating` четвёртым
  аргументом; неизвестная граница — `Infinity`. `getDivisionLetterByRating` принимает `(rating, game, season, eliteRating)`.
- `rankImageUrl` выбирает дивизион по правилам переданного сезона; явные новые дивизионы для старого сезона
  или WoT отображаются иконкой соответствующего ранга без буквы. `rankImageFallbackUrl` меняет оформление
  на `latest`, сохраняя смысл ранга исходного сезона.
- Статистика передаёт выбранный сезон в хелперы. Её текущие данные содержат один порог Легенды, поэтому
  она показывает Легенду без буквы. Песочница `/debug/game/comp7` позволяет проверить обе системы, все
  иконки и расчёт с тремя порогами Легенды.

Источник границ и процентов: [официальное руководство](https://tanki.su/ru/content/guide/game-events-rules/onslaught_guide/).

## Танки (`vehicles/`)

- Тег танка — строка вида `nation:Tag` (например `ussr:R45_IS-7`); `tankTagToReadable` (в `i18n/i18n.ts`) делает из тега читаемое имя, если нет локализации.
- `vehicle/VehicleImage.vue` + `utils.ts` — картинки танков (со `STATIC_URL`), `VehicleLevel.vue` — римские уровни (1–11), `type/VehicleType.vue` — иконки классов (LT/MT/HT/AT/SPG), `nations/` — флаги наций из спрайт-атласа (`atlases.json`, `Nation.vue`).
- `vehicleSearch.ts` — общий поиск техники для селектора и таблицы статистики. `createVehicleNameFilter(query)`
  возвращает функцию, принимающую отображаемое название: результат — `Highlighted` либо `null`.
  Поиск использует прежнюю логику селектора: буквы по порядку (например `kpz` → `Kanonenjagdpanzer`),
  без учёта регистра и диакритики. Селектор сохраняет ранжирование через `compareIntervals`.
  Локализацию, вариант имени и фильтры уровня/типа/нации задаёт вызывающий код.
  В селекторе поиск зависит от «полн./сокр.», в таблице статистики используется короткое имя.
  Теги и скрытые варианты названия дополнительно не проверяются.

## Арены (`arenas/`)

- `arenas.ts` — данные арен; тег арены — `spaces/xxx` (в локализации без префикса).
- `minimap/Minimap.vue` — миникарта с фоном (`minimapBackground/`) и базами (`minimapBases/`); фоны — со статик-сервера. Проп `size` (`'small' | 'medium'`, по умолчанию `'small'`) выбирает разрешение ресурса, но не CSS-размер компонента. `minimapUrl(tag, game, gameplay, format, size)` сохраняет прежние первые четыре аргумента: small-фоны лежат в `arenas/minimap/{tag}` (вариант Натиска — `minimap/comp7/{tag}`), medium — в `arenas/minimap-medium/{tag}/mmap` (вариант Натиска — `mmap_comp7`). Comp7-вариант выбирается только когда `getArenaMeta(...)?.minimap` содержит `_comp7`; при отсутствии меты возвращается обычный фон выбранного размера.

## Селекторы фильтров (`selectors/`)

Комплект UI для выбора фильтров статистики. Используется в `pages/replays/search/Index.vue` и секции фильтров `pages/infographics/pages/vehicles/`; `SearchLine` отдельно переиспользован в `onslaught/shared/settings/nicknameInput/`. В общих настройках сессионной инфографики этих селекторов **нет**.

- `vehicleSelector/` — выбор танков: содержимое `VehiclePopup` с виртуализированной таблицей `VehicleTable` внутри общего `PanelPopover`, бейджи выбранного (`VehicleSelectorBadges`). Круглая кнопка сброса фильтров и поиска использует `shared/ui/toolbarButton/ToolbarButton.vue`; без активных фильтров она остаётся в раскладке, но скрыта и недоступна.
  Alt/Option-клик по уровню, типу или нации выбирает все остальные пункты ряда; повторный
  оставляет только нажатый. Для наций учитывается только список текущей игры.
  Тултипы наций показываются над флагами и объединены в группу `vehicleFilters` с фильтрами таблицы техники:
  первый показ с задержкой 500 мс, последующие переходы внутри группы — без задержки.
- `arena/` — выбор карт (модалка + бейджи). В `ArenaSelectorPopup` круглый сброс поиска и фильтров использует `ToolbarButton`; без активных фильтров кнопка и соседний разделитель скрыты, а кнопка отключена.
- `gameVersionSelector/`, `gameSelector/` — версия игры и игра (Lesta/WG).
- `battleMode/BattleModeSelector.vue` — список в один столбец через стандартный `PanelPopover` и стандартные плитки `SelectionTile`. Первым идёт «Все режимы», затем Основные, Клановые, Особые, Обучение, События, Другое. Галочка третьей строкой шапки добавляет архивные в те же категории: оттенок текста и подпись «архив», оранжевая акцентная полоса только при выборе. Поиск по названиям и техническим кодам сохраняет иерархию и учитывает галочку архива.
  `v-model` — `BattleModeSelectionKey[]`: технический режим (`REGULAR`), пара (`REGULAR/assault`) или составная группа (`@battleRoyale`, `@training`); части технических ключей кодируются через `encodeURIComponent`. Пустой массив означает отсутствие ограничения. Основная зона выбирает любой геймплей режима или любой режим группы, три точки открывают компактный `PanelPopover` с одним уровнем вариантов. Подгруппы составных групп заданы явно и представлены секциями в этом же подменю, без дополнительных поповеров. Выбор подварианта выделяет и родительскую плитку, и кнопку с точками. `VERSUS_AI` называется «Полигон» и находится в Основных. У отдельного режима при одном видимом геймплее подменю не нужно. В группе случайных боёв WG подменю содержит стандартный геймплей, особый случайный бой и разминку; с архивом добавляются встречный бой и штурм.
  Составная группа показывает только явно заданные пункты и подгруппы; при единственном видимом пункте три точки скрыты. Заголовок секции скрыт, если в подменю осталась только одна секция. Бейдж у трёх точек показывает количество выбранных подвариантов, включая скрытые поиском или галочкой архива. Если среди выбранных подвариантов есть архивный, полоса родителя, активная кнопка с точками и бейдж становятся оранжевыми, в том числе при смешанном выборе.
  `multiple=true`, `selectionPriority="single"` по умолчанию: обычный клик выбирает один и закрывает панель, Ctrl/⌘/Shift переключают множественный выбор. При `selectionPriority="multiple"` обычный клик переключает пункт без закрытия; при `multiple=false` модификаторы игнорируются. Уточнение заменяет покрывающий его общий выбор, общий выбор удаляет дублирующие уточнения. Смена игры и скрытие архива сохраняют модель. При нескольких выборах кнопка показывает их количество.
  `game` фиксирует игру; `regions` преобразуется через `regionToGame` (пустой массив — обе игры). Эти пропы скрывают Lesta/WG. Без них начальная игра берётся из `preferredGameOrDefault`, дальнейшее переключение локально для экземпляра.
- `battleMode/catalog.ts` — каталог и представление селектора: ручные правила `initialCatalog` в формате `игра → режим → геймплей → ArchiveRule`, категории, составные группы, построение дерева, кодирование выбора и разворачивание `battleModeSelection(key)` в `{ title, targets: { mode, gameplay? }[] }` для потребителей. Каталог содержит 91 сочетание из `Event_OnBattleStart` на 29.09.2026 без CT (46 MT, 45 WG), без статических дат последних боёв. Правило каждой пары — `'archived'` (принудительный архив), `'active'` (принудительно актуальна) или `{ archived, inactiveDays, since? }`: `archived` задаёт статус до загрузки БД и при отсутствии корректной даты, `inactiveDays` — допустимое число суток без боёв, `since` — дата решения об архиве, которую могут отменить только бои строго после неё и внутри окна неактивности. Данные БД дополняют неизвестные пары и используются в рамках ручного правила известных пар. Актуальность в нескольких играх объединяется через OR. Новые неизвестные режимы попадают в «Другое» с техническими названиями; новые геймплеи отдельного режима дополняют его подменю; в families состав пунктов задаётся явно.
  `categories` содержит отдельные явные списки `mt` и `wot`; `families` общий для обеих игр. Категории можно независимо менять по составу и порядку. Для нескольких игр списки объединяются по названию категории, повторяющиеся ключи тайлов удаляются глобально; порядок и категория повторного ключа определяются первым появлением в списках выбранных игр. Режим, не классифицированный в выбранных играх, попадает в «Другое», даже если он классифицирован для другой игры. Геймплеи и архивность по-прежнему фильтруются по данным выбранных игр.
  `families.children` содержит пункты `{ mode, gameplay?, label? }` и явные подгруппы `{ label, children: { mode, gameplay?, label? }[] }`. Пункт без `gameplay` выбирает весь режим, с `gameplay` — конкретную пару; оба отображаются одним тайлом и не раскрываются автоматически. Подгруппа задаёт собственный заголовок и перечисляет пункты в одном подменю без дополнительного уровня поповеров. Необязательный `label` пункта переопределяет локализацию. Автоматический пункт «Любой геймплей» не добавляется; общий выбор режима можно явно включить в список собственным пунктом `{ mode, label }`. «Любой» в шапке выбирает все перечисленные цели, включая цели подгрупп. Тренировочные комнаты и виды турниров оформлены явными подгруппами со списками геймплеев; отсутствующие в выбранной игре и скрытые архивные варианты отфильтровываются. `@regular` содержит только `REGULAR/ctf`, `REGULAR/domination`, `REGULAR/assault`; `@regularNewbie` отдельно объединяет `RANDOM_NP2` («Новые аккаунты») и `WINBACK` («Вернулись в игру») в Обучении WoT. В Основных MT используется отдельный режим `REGULAR`, в WoT — `@regular`. Новые геймплеи не добавляются в families автоматически; общий выбор разворачивается именно в перечисленные цели. Прежние технические ключи сохраняют своё значение.
  Общие настройки: `defaultRule` — изначально актуальна, окно 365 дней; `softArchive` — изначально архивна, окно 30 дней, бои не позднее 30.09.2026 00:00 UTC не возвращают её в актуальные; `seasonal` — изначально актуальна, окно 36500 дней (около 100 лет); `historical` — изначально архивна, окно 30 дней. `COSMIC_EVENT` в обеих играх и `HALLOWEEN` / `HALLOWEEN_MEDIUM` / `HALLOWEEN_HARD` используют сезонное правило; прежний `HALLOWEEN_DEFENCE` остаётся мягко архивным. Исторический ивент использует месячное окно. `REGULAR/assault` и `REGULAR/domination` WG принудительно архивные. Для отдельной пары можно задать собственные значения, например `{ archived: true, inactiveDays: 30, since: '2026-09-30' }`, или использовать `'active'` / `'archived'` независимо от ответа БД.
  `@stories` объединяет `STORY_MODE`, `STORY_MODE_ONBOARDING`, `STORY_MODE_REGULAR` в «Сценарии» в категории Обучение. `TRAINING/bootcamp` («Учебный лагерь») остаётся в явной подгруппе «Тренировочные комнаты». Кнопка «Любой» справа в шапке подменю выбирает все перечисленные варианты группы. `@lastStand` объединяет `LAST_STAND`, `LAST_STAND_MEDIUM`, `LAST_STAND_HARD` в «Последний рубеж» с пунктами «Нормально», «Тяжело», «Жесть» и общим выбором «Любой» в шапке.
- `battleMode/useObservedBattleModes.ts` — ленивый запрос `game/battleMode/battleGameplay/max(dateTime)` из `Event_OnBattleStart` при открытии, где `RU/RPT → mt`, `EU/NA/ASIA/CN → wot`; тестовый `CT` и остальные коды регионов исключаются из загрузки. Общие состояние и дедупликация для экземпляров, кеш вкладки в `query`, серверный кеш 10 минут. Запрос и его кеш остаются внутри селектора, общий игровой домен их не загружает. Ошибка оставляет ручной каталог доступным и предлагает повторить запрос. Запрос намеренно читает всю историю, чтобы не потерять архив.

- Кнопки «Lesta / WG» внутри попапов техники, карт и версий пишут в **глобальный** `preferredGame` (`shared/global/`, localStorage), то есть локальный контрол фильтра меняет предпочтение игры на всём сайте. `GameSelector` к этому предпочтению, наоборот, не подключён.

`ArenaSelectorBadges` и `ArenaSelectorPopup` принимают необязательный `game`: с ним каталог показывает
заданную игру, скрывает переключатель Lesta/WG и не меняет глобальное предпочтение. Страница техники
передаёт игру, если все выбранные регионы относятся к одной игре; при смешанном или пустом выборе
регионов остаётся обычный переключатель.
Проп `allowTeamSelection` по умолчанию включён: выбор хранится как `tag:team`, у выбранной карты
можно указать команду. При `false` переключатель команд и базы на миникарте скрыты, а модель
содержит только теги карт; этот режим используется в статистике техники.

`BadgesLinePopover` хранит состояние открытия, считает целью всю строку бейджей и всегда монтирует `PanelPopover`. Параметры ширины, плотности, режима прокрутки, размещения и закрытия передаются панели через пропсы обёртки. `VehiclePopup` и `GameVersionPopup` выводят содержимое со своими шапками; их `TableView` прокручивается внутри панели с `scrollMode="child"`. Для селектора техники без бейджей и прямых примеров на `/debug` та же панель монтируется снаружи содержимого (см. 05).

### Выбор версии игры

`GameVersionPopup` получает из `GameVersions` строки вида `{ region, version }`, где `version` — например
`v.1.44.0.1 #1580`. Регулярное выражение разбирает её на три уровня: версия (`1.44`), патч (`1.44.0`) и
микропатч (`1.44.0.1 #1580`). Верхний уровень накрывает вложенные строки: вложенные варианты подсвечиваются как
`extended`, не выбираются и удаляются из модели при выборе верхнего уровня.
У исторических строк с условным хешем `#0000` доступны только уровни версии и патча;
несуществующий микропатч в попап не добавляется.

Модель попапа — `Set<OptionalRegionVersion>`, где `OptionalRegionVersion` — `{ version: string, region?: string }`:

- `withRegion` по умолчанию `false`: регион не участвует в выборе, а попап нормализует уже выбранные значения к
  `{ version }`;
- `withRegion=true`: регион входит в идентичность, поэтому одна и та же версия в разных регионах выбирается
  независимо;
- `versionToKey` / `keyToVersion` из `gameVersionSelector/utils.ts` кодируют регион и версию нулевым разделителем;
  это внутренний ключ выбора, не строка для SQL. Подпись бейджа строится отдельно: без региона `1.44`, с регионом
  `[RU] 1.44`.

`showVersions`, `showPatches` и `showMinor` управляют видимостью соответствующих секций попапа. Их нужно передавать
через `GameVersionSelectorBadges`; входной список и модель при этом не меняются. Боевой пример регионального выбора
только патчей — `pages/services/mt36.1/Index.vue`, где задано `with-region` и отключены `show-minor` / `show-versions`.

## Локализация и i18n

Два не связанных механизма:

1. **Имена игровых сущностей из БД** — `src/shared/i18n/i18n.ts`: запросы читают `VehiclesLocalizationDictionary`, `ArenasLocalizationDictionary`, `ArtefactsLocalizationDictionary`, `LootboxesLocalizationDictionary` и `CustomizationsLocalizationDictionary`. Ключ словаря — `(region, locale, tag)`, локализованные значения выбираются для фиксированной `LOCALE = 'RU'`, а при совпадении тега в нескольких регионах используется `localeRegionPriority`. Имена техники, карт и артефактов грузятся один раз с `LONG_CACHE`; основные хелперы — `getTankName(tag, short?)`, `getArenaName(tag)` и `getArtefactName(tag)`.
   - Страница лутбоксов использует те же dictionary-запросы для списка и названий контейнеров, расходников и кастомизаций. После агрегации до одной строки на `tag` локализация присоединяется через `LEFT ANY JOIN`.
   - Старые таблицы `*Localization` остаются в БД для обратной совместимости, но production- и debug-код фронтенда их больше не читает.
   - Ручные словари и фолбэки: `crewBookName`, `entitlementsName`, `getBestLocalization`; если перевода нет, UI показывает читаемый или исходный `tag`.
   - `countLocalize(count, 'запрос', 'запроса', 'запросов')` — русская плюрализация, используется часто.
2. **UI-переводы** — минималистичный `src/shared/i18n/useI18n.ts`: `useI18n(i18nRecord)` → `t(key)`; словари — локальные `i18n.json` рядом с фичей (пример: `pages/install/mods/i18n.json`, `shared/game/comp7/i18n.json`). Фолбэк be→ru→en. Большинство текстов при этом просто захардкожено по-русски в шаблонах — это норма проекта.
