## Ключевые факты (TL;DR)

- SPA на **Vue 3** (Composition API, `<script setup>`) + **TypeScript** + **Vite**, пакетный менеджер — **Bun**.
- `src/pages/metaStudio/` — студия по `/meta`; `src/meta/` — общий механизм Open Graph: протоколы, resolver, рендер и загрузка контекстов. Дизайн карточек, default-определение и общие контексты сайта — в `src/shared/ui/meta/`. Обычный `bun run build` собирает SPA и meta-артефакт (см. 11).
- Сайт **wotstat.info** — аналитика по игре «Мир танков» / World of Tanks на основе событий, собираемых игровым модом.
- Данные фронтенд берёт **напрямую из ClickHouse** (через web-прокси, пользователь `public`, база `WOT`) — бэкенда с REST API почти нет.
- Языки интерфейса: в основном русский (тексты захардкожены по-русски); точечная i18n есть только в отдельных местах.
- Новые юнит-тесты добавляем только по явному запросу пользователя. Для совместимости бинарных ссылок `compare` есть тест с фиксированными примерами — `bun run test` (см. [формат сравнения](comparison-query-format.md)). Основная проверка — `bun run build` (тесты → `tsc` и `vue-tsc` → три сборки Vite, с остановкой при ошибке) и ESLint. Руками компоненты проверяют на песочнице **`/debug`** (по подстранице на фичу, ссылок с сайта нет; см. 02).
- Два слоя общего UI: `shared/uiKit/` — переносимые компоненты и механизмы без проектных зависимостей, включая `queryStorage/`; `shared/ui/` — их имплементации под специфику сайта (см. 05).
- Стейт-менеджера (Pinia/Vuex) нет: состояние — локальное, `useLocalStorage` из VueUse и URL query-параметры.
