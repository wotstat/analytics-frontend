# Длина URL при упрощении игровых кодов

Замер от 10.10.2026. Рабочий формат сохранён; альтернативы проверены временными прототипами.
Это исторический замер с Base64url и отдельным байтом версии. Актуальный формат использует
Base62; его примеры и длины приведены в [comparison-query-format.md](comparison-query-format.md).

## Условия

Во всех вариантах используется один и тот же сериализатор compare: байт версии, флаги,
unsigned LEB128, UTF-8, raw DEFLATE уровня 9 только при уменьшении payload и base64url без padding.
Меняются только региональные ID и представление режимов. Каталоги в замере фиксированы и загружены,
содержат несколько известных танков/карт и явно синтетические ID для больших наборов.
Это сравнение конкретных моделей, а не утверждение о средней длине всех пользовательских ссылок.

Контекст страницы — RU/random, остальные фильтры без ограничений.
Числа в таблице — длина значения compare; полный URL
`https://wotstat.info/session/vehicles?compare=...` длиннее на 46 символов.
Длины полных ссылок приведены отдельно ниже.

- **Текущий:** бит HAS_REGION_FLAG выбирает внешний или записанный регион; короткие выборы режимов
  и частые пары имеют собственные коды, прочие пары вычисляются из явных кодов режима/геймплея.
- **Регион всегда:** каждый числовой ID хранит регион в четырёх младших битах;
  `encoded = id * 16 + regionCode`. Бита наличия региона и наследования контекста нет.
- **Режим + геймплей:** известный режим кодируется одним varint с битом HAS_GAMEPLAY_FLAG,
  при наличии геймплея записывается второй varint. Семейства имеют одно значение,
  неизвестные ключи — строковый fallback. Отдельного словаря частых пар и шага 16 нет.
- **Оба:** два предыдущих упрощения одновременно.

В прототипе режимов номер семейства идёт после известных режимов. При внедрении нужно
зафиксировать явные коды всего пространства, чтобы добавление режима не меняло коды семейств.
Пара режима/геймплея занимает два числа, поэтому прототип использует запись/чтение поля через
Writer/Reader; внедрение потребует изменить нынешний интерфейс одиночного CompactValue для режимов.

Большие наборы используют разные синтетические танки с ID от 100 с шагом 11.
Разные выборки дополнительно чередуют RU/EU/оба региона, четыре набора режимов, карты и взвод.

Все четыре варианта проверены на encode/decode/re-encode; после разрешения ID восстановленные
модели совпадают между вариантами. Сжатие одинаково включается в пяти случаях:
неизвестный танк/режим, 50/100 танков и 20/50 разных выборок.

## Вывод

На этих 18 состояниях упрощения не дали более коротких URL.
Постоянная запись региона добавляет до 17 символов; оба упрощения — до 20 символов.
Раздельные режим/геймплей обычно сохраняют длину, но три частые пары выросли с 12 до 16 символов,
а 50 разных выборок — с 532 до 535. В обычных коротких ссылках цена региона заметнее:
два танка выросли с 8 до 11 символов compare.

Сохранён текущий бинарный формат. Читаемость улучшена выделением encoding-модуля, явными
типизированными кодами и именованными битовыми флагами. Переход на упрощённый формат остаётся
отдельным решением о допустимом увеличении ссылок.
